# 胶片双机换卷推演台

供资料馆 / 小型影院在本地排练胶片双机（changeover）换卷的推演工具。
完全离线：后端只用 Python 标准库（`http.server` + `sqlite3`），
浏览器端为原生 HTML / CSS / JavaScript / SVG，无任何外部依赖。

## 启动

```bash
python3 server.py
```

然后打开终端中给出的地址（默认 <http://127.0.0.1:8000/>）。
数据保存在同目录 `changeover.db`（SQLite）。可用环境变量改地址：

```bash
HOST=0.0.0.0 PORT=9000 python3 server.py
```

首次启动会自动写入两个内置示例方案（规范稿 / 含冲突稿）。

## 工作模型

- 每卷记录：帧率、规格（35/16/8/Super 8，格/英尺自动换算）、画面长度
  （英尺 / 米 / 秒 / 格任选）、片头片尾护片、**马达提示**与**切换提示**所在帧。
- 提示位置可按放映习惯填「距画面末尾格数」（默认：12 英尺启动点、
  1.5 英尺切换点），也可在方案设置中改为「距物理片头」。
- 看不准的提示：填写起止范围并勾选「存疑」，时间轴上以斜纹区间表示，
  所有判定同时给出确定结论与「存疑可能」结论。
- 调度链：下一卷按自身马达提示预挂；上一卷马达提示到达片窗时启动下一台；
  下一卷动作片头时刻 = 上一卷马达提示 + 本卷「马达→切换」间隔。
  因此**标准双机（两卷提示间隔一致）空档/重叠为 0**；任一卷提示帧改错，
  差值即为银幕空档（黑场）或画面重叠，修改任一卷提示都会即时反映在
  其前、后两个衔接处与汇总/比较中。

## 功能

- **可缩放时间轴（SVG）**：银幕画面轨 + 甲/乙机泳道，显示每卷物理全片、
  启动/放映/片尾段、马达与切换提示（含存疑范围）、停机点、回卷就绪点、
  空档（斜纹）/重叠（红色）和周转余量连线。
- **拖拽换机调序**：拖动胶卷块到另一泳道换机、横向拖动调序；已核对的卷
  勾选锁定后禁止编辑与拖动；另有「自动交替」按钮。
- **自动换算**：启动、马达提示、切换、停机、回卷完成、再次就绪时刻，
  及马达→切换间隔、周转余量。
- **冲突检查**：提示范围倒置、提示越界/落入护片、马达/切换倒置、
  马达提前量不足、画面空档、画面重叠、片头储备不足、相邻卷同机、
  同一台机器来不及回卷周转。点击任一问题即定位相关卷并高亮对应提示输入框。
- **逐步模拟**：×1～×300 速度、上/下一提示跳转、自动跟随；同步高亮
  当前银幕卷、下一提示与倒计时，下方时刻表点击可跳转。
- **多方案**：方案库存取 / 复制 / 删除；方案比较表对照错误、警告、
  空档合计、重叠合计、周转缺口等（最优值标绿）。
- **实地排练**：从已保存方案冻结卷序与目标时刻，以实时时钟排练并
  记录每个动作的实际时刻（详见下节）。
- **拷贝验片单**：以一次放映涉及的实体胶片卷为对象逐卷验片，从已保存
  方案冻结卷序、片长、提示帧与护片参数；在可缩放 SVG 胶片带上按英尺 /
  时间码 / 格定位登记问题、记录处置与复查，未决项不放行（详见下节）。
- **导入导出 JSON**（单方案或 `{plans:[...]}` 批量）。
- **打印换机提示单**：A4 表格含每卷马达/切换时刻（分:秒 + 时:分:秒:格
  双行）、信号目标卷、间隔、启动/停机/就绪时刻，错误项开映前醒目列出。

## 实地排练

顶栏「实地排练」打开排练台（全屏视图）：

- **状态机**：`ready → running ⇄ paused → completed`（后端强制校验，
  非法流转返回 409）。新建排练时从**已保存**方案冻结卷序、全部目标
  时刻与存疑窗口，之后方案再修改不影响本次排练。
- **起始位置**：可从片头或任一卷开始；计时零点 = 该卷马达启动时刻，
  大时钟显示与提示单一致的计划时刻。
- **记录动作**：四个可配置热键（默认 Q/W/E/R）依次记下
  **启动下一台 / 切换画面 / 停机 / 回卷就绪**，也可点界面按钮。
  界面持续显示下一动作、倒计时与上一笔偏差；时间轴叠加实录标记
  （空心=计划，实心=实录，黄框=存疑窗口），下方复盘表逐项列出
  计划时刻、实际时刻、偏差与关联卷。
- **暂停/继续**：暂停只累计停表时长，继续后时间基准不变；
  刷新页面后排练状态与记录不丢。
- **纠错与问题标记**：误按可「撤销上一笔」；漏记、重复、乱序只
  标出问题（侧栏计数 + 表格标记），不自行补录。
- **存疑窗口**：提示存疑的动作按时间窗口判定，落在窗口内
  不算超前或延误；出窗按最近窗沿计偏差。
- **完成后不可改写**：`completed` 为终态，后端拒绝一切修改与删除
  （409），界面转为只读复盘。
- **排练对比**：并排比较同一方案的多次排练，按动作与衔接查看
  偏差变化（含平均/最大偏差、漏记/重复/乱序汇总，最优值标绿）。
- **导出与打印**：单次排练或所选多次排练可导出 JSON；
  「打印复盘单」输出 A4 复盘表（汇总 + 逐项记录 + 漏记明细 + 签字栏）。

## 拷贝验片

顶栏「拷贝验片」打开验片台（全屏视图）：

- **服务端冻结快照**：新建验片单时，后端从**已保存**关联方案生成并冻结
  卷序、规格 / 帧率、片长、片头片尾护片、马达 / 切换提示帧（含存疑范围）。
  客户端提交的卷数据只做严格核对，伪卷、改序或夹带检查结果均返回 409。
- **逐卷状态机**：`pending 待检查 → checking 检查中 ⇄ action 待处置
  → released 已放行 / returned 已退回`。待检查卷不得越级放行或退回；
  已放行、已退回为终态，后端拒绝改写（409）。
- **定位与登记**：可缩放 / 平移 SVG 胶片带显示护片段、画面段、片头储备、
  两个提示窗口与提示帧；支持英尺、`HH:MM:SS:FF` 时间码（格按本卷 fps）、
  格三种定位。可登记接片、齿孔、划伤、缩水、片头片尾、提示标记，
  附测量值、区间和严重程度；系统标注问题落在画面段、提示窗口、片头储备
  或护片段。
- **处置与复查**：记录清洁、重接、换护片、重做标记、保留待定。处置不会
  修改换卷方案。每个已处置问题必须在受影响区间留下一条真实、通过的复查
  记录，才可关闭；仅设置布尔位无效。复查未过自动转回保留待定。
- **放行闸与汇总**：仍有未决项的卷不能放行；页面汇总每卷开映准备状态。
  方案或卷参数后来变化只标记「快照过期」，已冻结数据与记录不变。
- **多次验片对比**：比较同一卷在多张验片单中的新增、撤销、严重程度 /
  处置 / 复查变化；支持导出单张或所选多张 JSON。
- **打印验片放行单**：逐卷带英尺定位刻度的微型胶片带、问题明细表、
  放行 / 退回章和验片员、放映员、放映主管、日期签字栏。

## 文件

```
server.py             标准库后端（静态文件 + SQLite JSON API：方案 + 排练 + 验片）
static/index.html     页面骨架（含排练台、验片台视图与弹窗）
static/style.css      样式（含 @media print 提示单/复盘单/验片放行单）
static/engine.js      纯函数推演引擎（单位换算 / 时刻链 / 冲突判定）
static/app.js         界面、SVG 时间轴、拖拽、模拟、方案与打印
static/rehearsal.js   实地排练：冻结计划、实时时钟、热键记录、对比与复盘单
static/inspection.js  拷贝验片：服务端快照、状态机、胶片带、处置复查与放行单
changeover.db         首次运行后生成
```
